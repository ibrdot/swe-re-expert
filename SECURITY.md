# Security reporting

Report sensitive defects privately to **[ibrdot@outlook.com](mailto:ibrdot@outlook.com)**.

Include the affected file, reproduction steps, environment, expected behavior,
actual behavior, and impact. Use a minimal fixture; do not email live samples,
credentials, or private data without first arranging an appropriate exchange.

The maintainer has not published a response-time commitment. For non-sensitive
bugs, use the public issue templates. Keep reproducible evidence separate from
assumptions about severity or exploitability.
