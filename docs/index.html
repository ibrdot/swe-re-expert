01 / SOURCE

Read the system.

Map architecture, investigate complexity, review dependencies, and prioritize changes with source-level evidence.

02 / BINARY

Recover the behavior.

Triage ELF/PE files, inspect disassembly, trace control flow, and separate suspicious signals from established facts.

03 / RESULT

Show your evidence.

Use structured reports with observations, confidence, severity, limitations, and the next useful action.

SCOPE > TRIAGE > DEEP DIVE > ASSESS > REPORT

A skill and supporting scripts, not a decompiler or an autonomous vulnerability scanner. Tool access and verified results depend on your environment.
