# Style References

**Not a menu — reference samples.**

The `.md` files here are **examples of how to describe a style** — how to put the visual language (palette, typographic feel, layout, materials) into words that GPT Image 2 can understand.

## ⚠️ Font Description Rule

**Describe the look, not the font name.**

| Wrong ❌ | Right ✅ |
|---------|---------|
| "Bebas Neue" | "bold condensed geometric sans-serif with tight tracking" |
| "Playfair Display" | "high-contrast display serif with hairline horizontals and thick verticals" |
| "Inter" | "clean geometric sans-serif with consistent stroke widths and moderate letter-spacing" |
| "Source Han Serif" | "high-contrast serif with elegant horizontal strokes and precise vertical strokes" |

GPT Image 2 is an image model and does not recognize font names; only visual descriptions actually influence the output.

## How to Use

When the AI plans a deck, it should:

1. **Analyze the content first** — tone, audience, medium
2. **Construct the visual language independently** — in your head, or directly in the prompt
3. **Consult these files only when needed** — borrow phrasing, copy sentence patterns, learn the right level of detail
4. **Or ignore them entirely** — styles not listed here can absolutely be invented from scratch

## How NOT to Use

- ❌ "Pick one and slot it in" (this is not a menu)
- ❌ Forcing yourself to use a file every time
- ❌ Treating these 14 entries as "the full space of possibilities"
