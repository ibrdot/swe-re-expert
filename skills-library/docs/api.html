One library.
Open by design.

A versioned, public JSON API generated from the same skill files as the website. No API key, backend, or package installation.

v1 / READ-ONLY / STATIC JSON

Endpoints

GETapi/v1/index.jsonDiscovery and API capabilities
GETapi/v1/skills.jsonAll guides with stable path-based keys
GETapi/v1/stats.jsonCounts, categories, and content revision
GETapi/v1/categories.jsonWorkflow categories and totals
GETapi/v1/collections.jsonCollection IDs, labels, and totals
GETapi/v1/skills/{key}.jsonOne guide's metadata and content hash
GETapi/v1/schema.jsonJSON Schema for the collection response

Fetch once. Filter your way.

const response = await fetch('https://ibrdot.github.io/ai-agent-skills/api/v1/skills.json');
if (!response.ok) throw new Error('Library unavailable');
const { skills, revision } = await response.json();
const matches = skills.filter(skill =>
  skill.name.toLowerCase().includes('review')
);

These endpoints are static files. Query parameters do not run server-side searches. Filter the response in your app; the explorer does the same.

Always generated. Never hand-counted.

Each repository push and manual workflow run regenerates the catalogue, Markdown index, JSON endpoints, detail records, and homepage totals. Validation checks that every actual SKILL.md is indexed exactly once. A content revision and per-guide SHA-256 make changes detectable.

Source content is not auto-imported from third-party repositories. Upstream changes still need review, including their license terms, before merging.

A small, honest contract.

Version 1 is additive: consumers should tolerate new fields. Skill keys are derived from file paths and change when a guide moves. The revision changes when indexed metadata or guide content changes. There are no write endpoints, authentication services, runtime integrations, or uptime guarantees beyond static hosting.

Saved guides in the explorer stay in your browser's local storage. They are not uploaded or synced to an account.
