# Roadmap

These are proposed directions, not shipped features or delivery commitments.

## Now

- Make first-run source and binary examples reproducible.
- Keep supported-format claims aligned with parser behavior.
- Grow regression tests around path handling and reference-count heuristics.

## Next

- Improve path-stable source findings and richer dependency resolution.
- Add PE fixtures and format-specific malformed-input tests.
- Rework evaluation rubrics to reward calibrated uncertainty and evidence.
- Expand illustrated case studies with independently checkable outcomes.

## Later

- Assess packaging and per-agent installation against actual supported interfaces.
- Evaluate broader format coverage before advertising feature parity.

Vote with a reproducible issue or a focused pull request, not a promise of magic.
